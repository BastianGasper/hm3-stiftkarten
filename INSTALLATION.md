# GitHub-Veröffentlichung – einmalige Schritte

1. https://github.com/new öffnen und unter deinem GitHub-Konto ein **öffentliches** Repository namens **hm3-stiftkarten** anlegen. Für einen initialen `main`-Branch empfiehlt es sich, **Add a README file** auszuwählen.
2. Über GitHub können die App-Dateien anschließend übertragen werden. `index.html` muss im Root des Repositories liegen.
3. In **Settings → Pages** die Source **Deploy from a branch** einstellen, darunter **main** und **/(root)** auswählen, **Save**.
4. Der Live-Link lautet dann: https://BastianGasper.github.io/hm3-stiftkarten/
5. Auf dem iPad den Link in Safari öffnen und über Teilen → Zum Home-Bildschirm installieren.

**Hinweis:** Deine Notizen und dein Fortschritt werden lokal gespeichert, nicht ins GitHub-Repository hochgeladen. Bitte regelmäßig Backups anlegen.
